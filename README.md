# Lakshmi's World

A small pixel-art open-world game about software engineer Lakshmi Shibu Raj's journey: NIT, the Royal Bank of Scotland, Citi, NYU, Simplian and a lab full of cloud projects.

**Play:** https://lakshmisraj.github.io/lakshmis-world/

- Move with the arrow keys or WASD; Space talks and squashes bugs; L opens the journey log; M toggles sound.
- On phones, use the on-screen pad and the A button.

One self-contained `index.html`, no build step.
